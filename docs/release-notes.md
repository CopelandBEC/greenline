Redline 1.1 — fast PDF markup for drawing, spec and deck review.

**Install (Windows 10/11, 64-bit):** download `Redline-1.1.0-setup.exe` below and run it. No admin rights needed; it installs for you only. Installing over 1.0 keeps your markups.
Because the installer isn't code-signed yet, Windows may show "Windows protected your PC": click **More info → Run anyway**.

**New in 1.1: select several markups at once**
- `Ctrl`+click (or `Shift`+click) adds a markup to the selection or removes it; this works in the markup list too.
- With Select `V`, drag on an empty part of the page to select every markup the box crosses (hold `Ctrl`/`Shift` to add to the selection). `Ctrl+A` selects everything on the current page.
- Move, delete, recolour (`1`–`6`), change line width (`[` `]`) or text size (`{` `}`), or duplicate (`Ctrl+D`) the whole selection in one go; `Ctrl+Z` undoes it in one step.
- Left-dragging on empty page space now draws the selection box instead of panning. To pan, use Space+drag, middle- or right-drag, or the wheel.

**Also in Redline**
- Single-key markup tools: Callout `C`, Text `T`, Cloud `K`, Rectangle `R`, Highlight `H`, Arrow `A`, Line `L`, Pen `P`, Select `V`.
- Page thumbnails `S`, all-pages overview `O`, markup list `M`, go to page `G`.
- Export: flattened PDF (`Ctrl+E`), editable PDF where each markup is a movable comment for Bluebeam/Acrobat (`Ctrl+Alt+E`), and a CSV comment list.
- Markups autosave as you work (in `%APPDATA%\Redline`); the original PDF is never changed.

Press `F1` in the app for all shortcuts and to set the name shown on your exported comments.
