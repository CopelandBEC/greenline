Greenline 1.5.1 — fast PDF markup for drawing, spec and deck review.

**Install (Windows 10/11, 64-bit):** download `Greenline-1.5.1-setup.exe` below and run it. No admin rights needed; it installs for you only. Installing over Redline or an earlier Greenline keeps your markups.
Because the installer isn't code-signed yet, Windows may show "Windows protected your PC": click **More info → Run anyway**.

**New in 1.5.1: a tidier toolbar, and zoom where you expect it**
- **Zoom menu.** Click the zoom percentage in the status bar: **Fit width**, **Fit page**, **Actual size**, or 50/100/200/400%. `W` and `F` still fit width and page from the keyboard.
- **A one-row toolbar.** The panel toggles now live under **Panels**, and the markup tools under the menu labelled with the active tool, so the bar no longer wraps onto a partial second row on ordinary windows. Colours, line width and text size stay one click away; Help moved to the right end of the status bar.
- **Proposed markups stand out more.** What an agent proposes with `greenline-cli` now sits on a faint orange wash inside its dashed outline — a little stronger while you hover its row in **Review** (`Y`) — so it reads clearly against your own markups.
- Menus close when picked with the keyboard, and the zoom menu is inactive in the overview, like the zoom keys.

Press `F1` in the app for all shortcuts and to set the name shown on your exported comments.
